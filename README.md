# Proteus Projects

Circuit simulations I built in **Labcenter Proteus** during my first year of Computer Engineering at KNUST.

## Projects

| Project | Description |
|---|---|
| [`inductors`](inductors) | Inductor circuit simulation, the companion to my [INDUCTORS](https://github.com/Oscar006-HUB/INDUCTORS) ESP32 experiment on back-EMF from an inductor/motor |

## Opening

1. Install **Proteus 8** or later.
2. Open `inductors/INDUCTORS.pdsprj`.

> This file was recovered from a Proteus autosave, so it holds the last autosaved state of the design.
